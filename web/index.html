Speech recognition and speech synthesis are browser features. Typed text is sent to the public MyMemory translation API only when you press Translate.
Browser speech recognition is not supported equally everywhere. Chrome/Edge usually provide the best experience. If microphone recognition is unavailable, type text manually; translation and speech playback can still work.
